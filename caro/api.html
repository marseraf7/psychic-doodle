API công khai (v1)

Dữ liệu chỉ đọc dạng JSON cho website, bot Discord / Telegram, công cụ thống kê.

  • Chỉ đọc
  • Không cần khoá
  • CORS mở
  • OpenAPI 3.1

Quy tắc chung

  • Địa chỉ gốc: /api/v1 (cùng tên miền với trang này).
  • Mỗi IP tối đa 120 lần / phút; quá thì trả 429 kèm Retry-After (giây).
  • Mọi câu trả lời có ETag: gửi lại trong If-None-Match để nhận 304 (không phải tải lại).
  • Lỗi luôn có dạng {"error": "not_found", "message": "Not found"}.
  • Không có dữ liệu riêng: email, bạn bè, người đã chặn, thiết bị. Ván gần đây chỉ trả khi người chơi để Lịch sử đấu ở chế độ Công khai; giải riêng tư / CLB / nháp không xem được.

Ký hiệu ô

Bàn cờ không giới hạn. Tên ô theo khung 15×15 quanh tâm: cột a…o từ trái sang, hàng 1…15 từ dưới lên, ô giữa là h8; ra ngoài khung vẫn đếm tiếp (cột p, q…, hàng 16…, hàng 0, -1…). Trong JSON, nước đi là [x, y]: x tăng sang phải, y tăng xuống dưới, [0, 0] = h8.

Public API (v1)

Read-only JSON data for websites, Discord / Telegram bots and stats tools.

  • Read-only
  • No key needed
  • Open CORS
  • OpenAPI 3.1

General rules

  • Base URL: /api/v1 (same domain as this page).
  • Each IP may make 120 requests / minute; beyond that you get 429 with Retry-After (seconds).
  • Every response carries an ETag: send it back in If-None-Match to get 304 (no re-download).
  • Errors always look like {"error": "not_found", "message": "Not found"}.
  • No private data: email, friends, blocked players, devices. Recent games are returned only when the player’s game history is Public; private / club / draft tournaments are not available.

Cell notation

The board is unlimited. Cells are named on a 15×15 frame around the center: columns a…o from left to right, rows 1…15 from bottom to top, the center is h8; beyond the frame the counting continues (columns p, q…, rows 16…, rows 0, -1…). In JSON a move is [x, y]: x grows to the right, y grows downward, [0, 0] = h8.

Открытый API (v1)

Данные только для чтения в формате JSON для сайтов, ботов Discord / Telegram и статистики.

  • Только чтение
  • Без ключа
  • Открытый CORS
  • OpenAPI 3.1

Общие правила

  • Базовый адрес: /api/v1 (тот же домен, что и у этой страницы).
  • С одного IP — не больше 120 запросов в минуту; сверх этого ответ 429 с заголовком Retry-After (секунды).
  • Каждый ответ содержит ETag: отправьте его в If-None-Match, чтобы получить 304 (без повторной загрузки).
  • Ошибки всегда имеют вид {"error": "not_found", "message": "Not found"}.
  • Никаких личных данных: email, друзья, заблокированные, устройства. Последние партии выдаются, только если история партий игрока открыта для всех; закрытые, клубные и черновые турниры недоступны.

Обозначение клеток

Доска не ограничена. Клетки называются по рамке 15×15 вокруг центра: столбцы a…o слева направо, ряды 1…15 снизу вверх, центр — h8; за рамкой счёт продолжается (столбцы p, q…, ряды 16…, ряды 0, -1…). В JSON ход — это [x, y]: x растёт вправо, y растёт вниз, [0, 0] = h8.

公开 API（v1）

只读 JSON 数据，可用于网站、Discord / Telegram 机器人和统计工具。

  • 只读
  • 无需密钥
  • 开放 CORS
  • OpenAPI 3.1

通用规则

  • 基础地址：/api/v1（与本页同一域名）。
  • 每个 IP 每分钟最多 120 次请求；超出时返回 429 并附带 Retry-After（秒）。
  • 每个响应都带有 ETag：在 If-None-Match 中发回即可得到 304（无需重新下载）。
  • 错误格式始终为 {"error": "not_found", "message": "Not found"}。
  • 不含私人数据：邮箱、好友、已屏蔽的玩家、设备。仅当玩家的对局记录设为公开时才返回最近对局；私密、俱乐部和草稿赛事不可查看。

格子记法

棋盘无边界。格子按中心周围的 15×15 框命名：列 a…o 从左到右，行 1…15 从下到上，中心为 h8；超出此框继续计数（列 p、q…，行 16…，行 0、-1…）。JSON 中一步棋为 [x, y]：x 向右增大，y 向下增大，[0, 0] = h8。
